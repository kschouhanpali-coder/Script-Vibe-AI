## ✨ Features

- ⚡ **Viral Script Generation** - AI-crafted scripts optimized for engagement and retention
- 🎯 **Niche Targeting** - Tech & AI, Finance, Health, Lifestyle, Gaming, Education, and more
- 🎭 **Tone Control** - Engaging & Fast-paced, Educational, Storytelling, Motivational, and more
- ⏱️ **Video Length Targeting** - Scripts for 1–2, 3–5, 5–7, or 10+ minute videos

- 🌍 **Multi-language Support** - English, Hindi, Spanish, French, and more

- 📝 **Raw Markdown View** - Copy the raw script and edit it in any tool
- 📊 **Video Metadata** - Auto-generated titles, descriptions, tags, and thumbnail ideas for YouTube SEO

## 🏁 Quick Start

### Use Online
No installation needed! [Launch the live demo](https://script-vibe-ai-mwtqtjlp27532narmb4mua.streamlit.app)

### Run Locally

**Prerequisites:** Python 3.10+ and a [Google Gemini API key](https://aistudio.google.com/app/apikey)

1. Clone the repository:
```bash
git clone https://github.com/kschouhanpali-coder/scriptvibe-ai.git
cd scriptvibe-ai
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Start the app:
```bash
streamlit run app.py
```

4. Enter your **Gemini API key** in the Studio Configuration panel

---

## 🎯 How to Use

1. **Connect** - enter your Gemini API key in the Studio Configuration panel
2. **Describe** - write your **Video Concept / Topic** in plain language
3. **Configure** - pick niche, tone, length, audience, hook style, and language
4. **Generate** - click **⚡ GENERATE VIRAL SCRIPT**
5. **Review** - switch between the Studio, Raw Markdown, and Metadata views
6. **Record** - open the Teleprompter view and start filming
